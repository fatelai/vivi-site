# Vivi 網站：小編使用手冊

## 登入

1. 打開 **`網站網址/admin/`**（例如 `https://帳號.github.io/vivi-site/admin/`）。
2. 用你收到邀請信的 Email 登入。第一次登入要先到信裡的連結建立帳號。

## 畫面說明

- **左邊**：可以修改的欄位，依網頁區塊分類。
- **右邊**：網站預覽。左邊改什麼，右邊馬上跟著變。

## 修改文字

**方法一：直接點網頁**
在右邊預覽畫面點想改的文字，左邊會自動跳到那個欄位。

**方法二：從左邊找**
點左邊的區塊名稱（例如「課程介紹」），再找到要改的欄位。

| 區塊 | 內容 |
|---|---|
| 首頁大圖區 | 最上面的大標題、介紹文字、背景圖、按鈕文字 |
| 關於我 | Vivi 的照片、介紹段落、數字亮點、專長標籤 |
| 課程介紹 | 每一門課的名稱、標籤、說明、時長、價格、圖片 |
| 近期場次 | 每一場的日期、時間、名稱、備註 |
| 影片 | 貼上 YouTube 或 Instagram 貼文／Reels 網址就會嵌入播放器；清單是空的時整個區塊會隱藏 |
| 學員回饋 | 回饋內容和學員名稱 |
| 預約區塊 | 頁面下方色塊的標題、說明、按鈕文字 |
| 報名連結 | 所有「預約」按鈕要連到的 LINE 網址 |
| 網站配色 | 按鈕色、主背景色、區塊背景色 |
| 頁尾與聯絡方式 | 上課地址、Email、電話、LINE、社群連結、版權文字（沒填的項目不會顯示） |
| Logo 文字 | 左上角的「Vivi Sound Healing」 |
| 網頁標題與描述 | 瀏覽器分頁標題、Google 搜尋結果顯示的文字 |

標示「**按 Enter 換行**」的欄位，按 Enter 會在網頁上換行。

## 換圖片

1. 點右邊預覽的圖片，或在左邊找到圖片欄位。
2. 點圖片 → 上傳新圖片，或從已上傳的圖片中選一張。
3. 建議尺寸：
   - 首頁背景圖：橫式，寬 1920 像素左右
   - Vivi 照片：直式（4:5），寬 900 像素左右
   - 課程圖片：橫式（4:3），寬 800 像素左右
4. 檔案太大會讓網站變慢，單張圖片盡量在 500 KB 以內。

## 新增、刪除、調整順序

課程、學員回饋、近期場次、數字亮點、證照、社群連結都是清單：

- **新增**：點清單下方的「+」按鈕。
- **刪除**：點項目右邊的「⋯」或垃圾桶圖示。
- **調整順序**：按住項目左邊的拖曳圖示上下移動。

## 更換 LINE 預約連結

1. 左邊點「**報名連結**」。
2. 貼上 LINE 官方帳號或個人 LINE 的加好友連結。
3. 存檔。網站上所有「預約」按鈕都會改連到這個網址。

## 調整網站配色

1. 左邊點「**網站配色**」。
2. 點色塊用調色盤選顏色，或直接輸入色碼（例如 `#8a6a3b`）。右邊預覽會馬上變色。
   - **按鈕色**：預約按鈕，也會用在英文小標、場次日期、下方預約區塊。按鈕上的字是白色，請選深一點的顏色，字才看得清楚。滑過按鈕時的顏色會自動調深。
   - **主背景色**：整頁的底色。
   - **區塊背景色**：課程等交錯區塊的底色，建議和主背景色差一點點。
3. 存檔。想換回原本的顏色：按鈕 `#8a6a3b`、主背景 `#fbf7f1`、區塊背景 `#f2ebe0`。

## 存檔

- 改完按左下角 **Save**。
- 存檔後約 **1～2 分鐘** 網站才會更新，這段時間看到舊內容是正常的。
- 改錯了還沒存檔，按 **Reset** 可以恢復。

## 注意事項

- 不要同時有兩個人改同一個區塊，後存檔的人會蓋掉前一個人的修改。
- 存檔前先看右邊預覽，確認手機版排版也正常：把瀏覽器視窗縮小就能看到手機版的樣子。
- 遇到問題，請截圖給網站開發者。
